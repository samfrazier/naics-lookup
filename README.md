# naics-lookup
Find the NAICS industry code for what you actually sell, using ordinary words. 

NAICS codes gate federal contracting: your SAM.gov registration, set-aside
eligibility, and every solicitation search key off them. But the official
reference is a 1,000-page manual of phrases like "Industrial and Personal
Service Paper Merchant Wholesalers," and Census's own search tool assumes you
already know the vocabulary. This tool goes the other direction — you type
"toner cartridges and copy paper," it returns ranked candidate codes with the
official evidence for each match.
